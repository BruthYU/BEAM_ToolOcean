# 虚拟细胞模型的临床主题集成与辅助诊断应用构想

> 文档类型：技术与产品规划报告
>
> 更新日期：2026-10-27
>
> 关联资料：[虚拟细胞模型综述表](./virtual_cell_models_survey.md)｜[Excel 版本](./virtual_cell_models_survey.xlsx)

## 1. 执行摘要

现有虚拟细胞模型覆盖单细胞转录组、多组学、空间组学、病理与显微图像、药物/基因扰动以及机制型细胞模拟。它们适合被组合成面向临床主题的工具链，但不宜将 100 个模型简单串联，也不应直接输出未经验证的自动诊断结论。

建议建设一个“临床主题路由式虚拟细胞平台”：先根据疾病、样本类型、组学模态和临床问题选择模型，再组合基础表征、多组学融合、空间微环境、扰动模拟和证据校验模块。系统最终输出带证据、置信度和适用范围的辅助诊断或科研决策报告。

首个最适合落地的方向是“肿瘤多组学辅助分型与虚拟用药”，核心能力包括：

- 肿瘤与免疫细胞识别、异常细胞状态检测。
- 分子亚型、免疫生态型和空间微环境分析。
- 候选药物、剂量、组合和靶点的虚拟扰动。
- 耐药状态、残留细胞群和序贯治疗探索。
- 自动生成包含证据、不确定性和验证建议的报告。

系统在早期应定位为科研与临床决策支持，而不是替代医生、病理诊断或体外药敏实验。

## 2. 建设目标与边界

### 2.1 建设目标

1. 将分散的虚拟细胞模型封装成统一、可调用、可比较的工具。
2. 从“按技术分类”升级为“按临床问题编排”。
3. 支持从患者样本到细胞状态、疾病机制、候选治疗和验证建议的完整流程。
4. 保存每一步输入、模型版本、参数、证据和不确定性，保证结果可追溯。
5. 允许新模型快速加入，同时通过统一基准决定其是否进入临床工作流。

### 2.2 使用边界

- 基础模型生成的是统计预测，不等同于疾病机制已经得到证明。
- 药物扰动预测不能替代药敏实验、临床试验或医生处方判断。
- 许多 2025–2026 年模型仍是预印本，可能缺少独立复现和跨中心验证。
- 对训练数据之外的人群、组织、疾病和测序平台，必须执行分布外检测并允许系统拒答。
- 涉及正式诊断、预后或治疗推荐时，需要完成回顾性验证、前瞻性验证、临床审核和相应监管流程。

## 3. 总体系统架构

```mermaid
flowchart LR
    A[患者样本与临床资料] --> B[数据质控与标准化]
    B --> C[细胞/组织统一表征]
    C --> D[多组学与空间融合]
    D --> E[疾病主题分析]
    E --> F[药物和基因扰动模拟]
    F --> G[多模型校验与不确定性]
    G --> H[辅助诊断和治疗研究报告]
    H --> I[医生审核/实验验证/随访反馈]
    I --> B
```

系统分为六层：

| 层级 | 主要职责 | 代表模型 |
|---|---|---|
| 数据接入层 | 接收单细胞、Bulk、多组学、空间组学、病理图像和临床元数据 | 数据转换与质控工具，不绑定单一模型 |
| 基础表征层 | 细胞嵌入、细胞注释、异常状态发现、参考图谱检索 | UCE、TranscriptFormer、CellFM、SCimilarity、scGPT、Geneformer |
| 多组学融合层 | RNA、蛋白、ATAC 等联合分析与缺失模态补全 | CAPTAIN、CellHermes、SCARF、totalVI、MultiVI、scGLUE、MOFA+ |
| 空间组织层 | 组织区域、空间生态位、细胞通讯和微环境分析 | Nicheformer、NicheCompass、Novae、VirTues、STPath、cell2location |
| 扰动模拟层 | 药物、靶点、剂量、组合、细胞命运和耐药模拟 | State、PIE、Tahoe-x1、X-Cell、SCALE、TxPert、CPA、CellOT、GEARS |
| 临床解释层 | 多模型共识、不确定性评估、证据追踪和报告生成 | 规则引擎、知识库、校准器和人工审核模块 |

## 4. 按临床主题组织的任务包

### 4.1 肿瘤诊断、分型与精准治疗

| 可执行任务 | 输入 | 推荐模型组合 | 输出 |
|---|---|---|---|
| 肿瘤细胞与正常细胞识别 | scRNA-seq、CITE-seq、病理图像 | CellSAM + CellFM/SCimilarity + CAPTAIN | 细胞类型、恶性概率、异常细胞群 |
| 肿瘤分子亚型判定 | 单细胞或 Bulk 表达、临床标签 | TranscriptFormer/CellFM + BulkFormer + 本地分类器 | 亚型概率、关键基因和通路证据 |
| 免疫微环境分型 | 空间转录组、空间蛋白、H&E | NicheCompass + VirTues + STPath | 炎症型、免疫排斥型或免疫荒漠型等特征 |
| 候选药物筛选 | 患者细胞状态、候选药物和剂量 | State + Tahoe-x1 + X-Cell + CPA | 药物响应排名、受影响细胞群、预测置信度 |
| 联合与序贯治疗探索 | 药物组合、纵向表达和细胞丰度 | X-Pert/TxPert + U-Pert + SequenTx | 组合增益、耐药风险、序贯策略候选 |
| 复发与残留状态分析 | 治疗前后单细胞/空间数据 | CellOT + SCALE + SpatialProp | 残留亚群、状态转移、复发相关通路 |

一个完整病例报告应至少包含：肿瘤细胞组成、分子亚型、免疫生态型、可干预通路、候选药物、潜在耐药机制、毒性风险以及建议验证实验。

### 4.2 免疫与炎症疾病

可操作任务包括：

- T、B、髓系细胞亚群及异常活化状态识别。
- 疾病活动期与缓解期细胞状态比较。
- 细胞因子阻断、免疫抑制剂和生物制剂响应预测。
- 致病细胞—组织邻域及细胞通讯分析。
- 治疗后免疫重建与副作用相关状态监测。

推荐组合为 CAPTAIN/totalVI 进行 RNA—蛋白联合表征，NicheCompass 分析组织生态位，State/OCOO-T/CellOT 进行干预状态预测，ProteinTalks 补充蛋白层机制证据。

### 4.3 血液系统疾病

可操作任务包括：

- 骨髓和外周血细胞自动注释。
- 白血病、淋巴瘤等异常细胞群识别。
- 细胞分化阻滞和克隆状态分析。
- 治疗前后微小残留病灶的研究性检测。
- 靶向药物或组合治疗的细胞状态预测。

推荐使用 SCimilarity/CellFM 进行参考图谱匹配，scPRINT/RegFormer 解析调控网络，CAPTAIN 融合表面蛋白，State/X-Cell/GEARS 评估药物或基因靶点。

### 4.4 罕见病与遗传病

可操作任务包括：

- 候选致病基因和调控元件排序。
- 判断变异主要影响哪些细胞类型和组织。
- 模拟基因敲低、敲除、过表达或功能恢复。
- 从异常状态反推可能的救援靶点。
- 为类器官或细胞实验推荐验证基因和 readout。

推荐使用 GET/EpiAgent 分析调控影响，Geneformer/RegFormer/scPRINT 构建基因网络，PIE/X-Cell/GEARS 进行扰动推断。输出应是“功能证据和候选优先级”，而不是直接给出致病性定论。

### 4.5 数字病理与空间诊断

可操作任务包括：

- 细胞、细胞核和组织区域分割。
- 肿瘤边界、坏死区、免疫热点和侵袭前沿识别。
- 从 H&E 预测探索性的空间表达或细胞表型。
- 明场图像虚拟染色与多通道生成。
- 将病理图像与空间 RNA/蛋白共同用于分型。

推荐流程为 CellSAM 完成细胞分割，STPath/FmH2ST 进行图像—表达映射，Novae/Nicheformer 识别组织区域，VirTues 分析空间蛋白，MONET 用于研究性虚拟染色。

### 4.6 药物安全性与毒性

可操作任务包括：

- 预测药物在正常细胞中的非预期响应。
- 识别肝、心、肾、免疫等高风险细胞类型。
- 比较不同剂量下的毒性通路与治疗窗口。
- 检测细胞周期、凋亡和应激异常。
- 将转录组响应与形态变化、蛋白变化进行交叉验证。

推荐组合为 Tahoe-x1/X-Pert/scCycleMol 预测表达和细胞周期，ProteinTalks 验证蛋白通路，FORM/CellFluxV2 分析形态表型。该方向更适合药物研发和临床前安全评价，不适合单独形成患者用药结论。

### 4.7 感染性疾病与宿主反应

可操作任务包括：

- 区分感染、旁观者和免疫应答细胞状态。
- 识别病原相关宿主通路和炎症失衡。
- 模拟宿主靶向治疗或抗感染药物的细胞响应。
- 分析免疫细胞与感染组织的空间关系。
- 对细菌最小细胞或代谢机制开展机制模拟。

可组合 TranscriptFormer/UCE 进行跨物种表征，State/TxPert 预测宿主扰动，NicheCompass 分析空间免疫环境，E-CELL/VCell/整细胞模型承担机制研究。

## 5. 建议封装的标准工具接口

平台不直接暴露模型名称，而是提供稳定的临床任务接口。模型升级时，接口和输出格式保持稳定。

| 工具接口 | 主要功能 | 输入 | 标准输出 |
|---|---|---|---|
| `ingest_patient_sample` | 数据接入、脱敏、格式检查和样本登记 | count 矩阵、图像、临床元数据 | 标准样本对象、质控报告 |
| `annotate_cells` | 细胞类型和状态注释 | 单细胞/空间表达、可选蛋白数据 | 标签、概率、参考图谱相似度 |
| `detect_abnormal_states` | 异常、恶性或疾病相关状态识别 | 患者细胞与参考队列 | 异常分数、关键特征、相似病例 |
| `integrate_multiomics` | RNA/ATAC/蛋白联合表征和模态补全 | 多组学矩阵、配对关系 | 联合嵌入、补全值、模态一致性 |
| `reconstruct_tissue_niche` | 空间区域和细胞生态位分析 | 空间表达、坐标、病理图像 | 空间域、邻域、细胞通讯和热点 |
| `infer_disease_subtype` | 分子亚型和免疫生态型预测 | 患者表征、临床变量 | 亚型概率、支持证据和置信区间 |
| `simulate_drug_response` | 药物、剂量和细胞背景响应模拟 | 基线细胞、药物、剂量 | 预测细胞分布、差异基因和通路 |
| `simulate_gene_perturbation` | 基因敲除/激活和组合扰动 | 基线细胞、靶基因 | 预测状态、效应基因和不确定性 |
| `rank_treatments` | 多模型候选治疗排序 | 扰动结果、临床约束 | 候选排名、获益/风险及模型分歧 |
| `assess_resistance` | 耐药状态和逃逸通路分析 | 治疗前后或模拟数据 | 耐药亚群、通路、替代干预候选 |
| `assess_toxicity` | 正常细胞和组织毒性预测 | 正常参考、药物和剂量 | 易损细胞、毒性通路和风险等级 |
| `generate_clinical_report` | 汇总证据并生成可审核报告 | 所有模块输出 | 结构化报告、证据链、限制和建议 |

每个接口都应返回以下公共字段：

- 模型名称、版本、权重和运行参数。
- 输入数据版本、质控结果和缺失信息。
- 预测值、置信度和校准状态。
- 是否属于训练分布、是否触发拒答。
- 支持证据、模型分歧和已知限制。
- 推荐的实验验证、追加检测或人工审核动作。

## 6. 模型编排策略

### 6.1 不采用“一个模型包打天下”

每项临床任务建议使用三类角色：

1. **主模型**：产生主要结果，例如 State 预测扰动响应。
2. **独立复核模型**：采用不同建模路线重复预测，例如用 CellOT 或 CPA 复核。
3. **基线与规则模型**：使用差异表达、通路评分、传统统计或临床规则建立下限。

只有当主模型、复核模型和基础证据方向一致时，结果才进入高优先级候选；模型分歧必须在报告中呈现。

### 6.2 临床主题路由规则

路由器至少考虑：

- 疾病领域和临床问题。
- 输入模态、样本数量和数据质量。
- 单细胞、Bulk、空间或图像尺度。
- 是否要求未见药物、未见细胞类型或跨数据集外推。
- 模型训练数据是否覆盖当前组织、疾病和人群。
- 是否有公开权重、推理代码和可复现评测。
- 是否经过本地队列验证。

优先选择有公开实现、正式发表、外部验证和不确定性输出的模型。预印本模型可进入研究沙箱，但不直接进入临床报告主结论。

## 7. 示例：肿瘤病例端到端工作流

### 7.1 输入

- H&E 全切片图像。
- 肿瘤组织 scRNA-seq 或单细胞多组学。
- 可选空间转录组/空间蛋白数据。
- 基因变异、既往用药、病理诊断和疗效信息。
- 一个受临床规范约束的候选药物集合。

### 7.2 处理流程

1. 对样本、批次、细胞和图像执行质控。
2. 使用 CellSAM 分割图像，使用 CellFM/SCimilarity 标注细胞。
3. 识别肿瘤细胞、免疫细胞、基质细胞及异常状态。
4. 使用 CAPTAIN/totalVI 融合 RNA 与蛋白信息。
5. 使用 NicheCompass/VirTues 构建空间微环境和免疫生态型。
6. 使用 State/Tahoe-x1/X-Cell 对候选药物进行虚拟扰动。
7. 使用 CPA/CellOT 或传统差异分析复核预测方向。
8. 使用 U-Pert/SequenTx 探索残留亚群、耐药及序贯方案。
9. 对正常细胞执行毒性筛查，并标注缺少正常组织覆盖的风险。
10. 生成结构化报告并交由分子肿瘤专家组审核。

### 7.3 输出报告

- 样本质量和数据适用性。
- 肿瘤分子亚型和主要细胞状态。
- 免疫生态型和关键空间邻域。
- 候选药物及多模型共识排名。
- 每种药物可能影响的肿瘤、免疫和正常细胞群。
- 潜在耐药机制和替代靶点。
- 不确定性、分布外风险和模型分歧。
- 建议的类器官、Perturb-seq、蛋白或病理验证实验。

## 8. 临床成熟度分级

| 等级 | 定义 | 适合任务 | 使用方式 |
|---|---|---|---|
| L1：研究工具 | 未完成临床验证，用于机制和假设发现 | 细胞注释、通路分析、虚拟扰动、候选靶点发现 | 科研环境，不进入临床结论 |
| L2：转化研究工具 | 已完成独立回顾性队列验证 | 辅助分型、患者分层、疗效关联和风险研究 | 医生可查看，但不能单独决策 |
| L3：临床决策支持 | 完成前瞻性、多中心和流程验证 | 辅助诊断、预后或治疗优先级 | 医生审核后使用，受质量体系管理 |
| L4：受监管临床产品 | 满足适用地区法规与持续监测要求 | 明确限定场景下的临床功能 | 按批准范围部署和更新 |

当前多数虚拟细胞模型处于 L1，少量基础分析能力有机会较快进入 L2。药物推荐、治疗序列和自动诊断属于高风险能力，应从 L1 开始逐级验证。

## 9. 评测与验证设计

### 9.1 分析有效性

- 数据格式、重复性、批次鲁棒性和缺失模态稳定性。
- 细胞注释准确率、图像分割 Dice/IoU、空间区域一致性。
- 推理时间、硬件成本和失败率。

### 9.2 模型有效性

- 跨患者、跨中心、跨平台和时间外验证。
- 未见细胞背景、未见药物和组合扰动评测。
- 差异表达方向、效应量、细胞分布和通路一致性。
- 概率校准、置信区间和分布外检测能力。

### 9.3 临床有效性

- 与病理诊断、分子分型、药敏实验和真实疗效比较。
- 与指南、分子肿瘤专家组和标准统计模型比较。
- 按人群、性别、年龄、种族、组织和中心进行亚组评估。

### 9.4 临床效用

- 是否减少人工分析时间。
- 是否提高可验证靶点或候选药物命中率。
- 是否改善报告一致性和专家决策效率。
- 是否在真实流程中减少无效检测或不必要实验。

## 10. 数据、安全与治理要求

- 患者数据必须脱敏，并执行访问控制、审计和最小权限原则。
- 原始数据、参考图谱、模型权重和报告应分别版本化。
- 禁止将机构外数据直接用于模型再训练，除非获得明确授权。
- 每次结果必须能追溯到样本、预处理、模型、参数和知识库版本。
- 对预印本、闭源权重和训练数据不透明的模型设置醒目标记。
- 建立模型更新后的回归测试，防止新版本改变既有临床结论。
- 设置拒答条件：样本质量不足、模态缺失严重、分布外或模型间高度冲突时不生成结论性建议。

## 11. 建议的 MVP 与实施路线

### 第一阶段：肿瘤研究型 MVP（0–3 个月）

- 建立统一样本对象和模型注册表。
- 接入 scRNA-seq、CITE-seq、H&E 和基本临床元数据。
- 实现细胞注释、异常状态、微环境和候选药物扰动四类工具。
- 使用公开队列完成离线回放，不接入真实临床决策。

### 第二阶段：本地回顾性验证（3–6 个月）

- 接入本地已脱敏肿瘤队列。
- 比较模型结果与病理、分子检测、药敏和随访结局。
- 建立模型共识、不确定性和拒答机制。
- 固化第一版结构化报告。

### 第三阶段：多中心与前瞻性影子运行（6–12 个月）

- 增加空间组学、多组学和纵向样本。
- 在不影响临床决策的条件下进行影子运行。
- 记录医生是否采纳、模型是否提供新增信息以及失败模式。
- 完成跨中心、跨设备和亚组公平性评估。

### 第四阶段：限定场景临床决策支持（12 个月以后）

- 选择一个边界明确、证据充分的临床任务。
- 建立质量管理、版本锁定、持续监测和人工复核流程。
- 根据应用地区和使用方式开展法规与伦理评估。

## 12. 优先级建议

建议按照以下顺序推进：

1. **优先级一：肿瘤细胞注释与微环境报告。** 输入输出清晰，模型较成熟，容易使用病理和专家结论验证。
2. **优先级二：候选药物虚拟筛选。** 临床价值高，但必须结合体外实验和多模型复核。
3. **优先级三：治疗前后状态与耐药分析。** 需要纵向样本，但适合形成差异化能力。
4. **优先级四：罕见病基因功能解释。** 可显著缩小实验验证范围，但不能直接替代遗传诊断标准。
5. **长期探索：患者级数字细胞/组织孪生。** 需要多模态、时间序列和机制参数，目前主要属于研究方向。

## 13. 结论

虚拟细胞在临床方向最现实的价值，不是直接取代医生做诊断，而是把单细胞、多组学、空间病理和扰动预测组织成一条可追溯的证据链。近期可优先实现细胞识别、疾病分型、微环境分析、候选治疗排序和耐药机制提示；中长期再逐步发展患者级动态模拟与数字孪生。

产品设计的关键是按临床主题编排工具、用多模型和传统方法相互校验、显式报告不确定性，并将实验验证和医生审核保留在闭环中。
